# Mianwali3D

A real-world 3D map project focused on Mianwali, Pakistan.

## Current Map Area
- Start: Mianwali Toll Plaza
- Destination: Watta Khel Chowk
- Road: M.M. Road
- Corridor: 100 metres on each side of the road centreline

## Tools
- Blender 5.3
- OpenStreetMap data
- Osmium Tool
- Python
- VS Code

## Project Structure
- `blender/` - Blender project files
- `data/` - Geographic source data (large files excluded from Git)
- `exports/` - Exported map assets
- `scripts/` - Processing scripts
